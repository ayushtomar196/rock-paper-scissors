# Rock Paper Scissors Game

## About the Project
This is a simple Rock Paper Scissors game made using Python.
The player plays the game against the computer(other_player).

## How the Game Works
The player enters either rock, paper, or scissors.
The computer randomly selects one option.
Then the program compares both choices and displays the result.

## Rules
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
Same choices result in a draw

## Requirement
Python 

## How to Run
Open the terminal in the project folder and run:

python project.py

Variables
User input

 Lists
